# اِقْرَأْ وَارْتَقِ – القرآن الكريم للحفظ والمراجعة

تطبيق Flutter متكامل لطلاب الخلاوي وحلقات التحفيظ وكل راغب في حفظ القرآن
الكريم ومراجعته: استماع لتلاوة **الشيخ الزين محمد أحمد**، متابعة النص
العثماني متزامنة مع الصوت، و**تكرار دقيق للآيات** بعدد يحدده المستخدم.

- مُعرّف التطبيق: `com.tayeb.wird` — الإصدار 1.1.0+2 — minSdk 24
- الهوية البصرية: **ثيم بمبي نسائي** (وردي عميق `#AD1457`، وردي `#EC407A`،
  وردي فاتح، لمسات ذهبية خفيفة) — `lib/core/theme.dart`.

## خاصية «واقف وين؟» (جديد في 1.1.0)

علامة وقوف واحدة محفوظة محليًا (سورة + آية + تاريخ التثبيت) عشان ما تنسى
حفظت لحدي وين:

- التثبيت من: قائمة الآية في المصحف («أنا واقف هنا»)، زر في شاشة المشغّل،
  أو زر «ثبّت وقوفي عند آخر آية في النطاق» في شاشة الحفظ.
- الشاشة الرئيسية تعرض بطاقة بمبي «واقف وين؟» فيها الموضع و«منذ متى»
  (اليوم/أمس/منذ X أيام) وثلاثة أزرار: كمّل من هنا / اسمع من هنا / كرّر من هنا.
- الآية المثبّتة تظهر في المصحف بإطار وردي وشارة «موضع الوقوف»، وفي فهرس
  السور تظهر أيقونة إشارة وردية بجانب سورتها.
- **تقديم تلقائي:** عند إتقان آية عند العلامة أو بعدها تنتقل العلامة للآية
  التالية وحدها (منطق نقي مختبَر في `lib/core/standing_marker.dart`)،
  ويمكن إيقافه من الإعدادات: «تقديم علامة الوقوف تلقائيًا عند إتقان آية».
- يعمل دون إنترنت في: النص الكامل، التقدّم، المفضلة، والسور التي نزّلها
  المستخدم بنفسه.

## كيف يعمل تكرار الآيات؟ (القلب التقني)

موقع mp3quran يوفر **توقيت بداية ونهاية كل آية** داخل ملف السورة
(`api/v3/ayat_timing?read=13`). لذلك:

1. `RepetitionEngine` (Dart نقي، `lib/core/repetition_engine.dart`) يحوّل
   النطاق المطلوب إلى قائمة مقاطع زمنية بحسب النمط:
   كل آية وحدها / مجموعات آيات / النطاق كاملًا، وبعدد التكرار المطلوب
   (١، ٢، ٣، ٥، ١٠، مخصص، أو مستمر).
2. `AudioController` يشغّل كل مقطع عبر `ClippingAudioSource` بقصّ ملف
   السورة بين بداية الآية ونهايتها، ولا يُبلّغ المحرك بالاكتمال إلا عند
   انتهاء المقطع فعليًا — فشل التحميل أو التقديم **لا يُحتسب** تكرارًا.
3. الفاصل الزمني الاختياري يُطبّق بين المقاطع، والوضع المستمر يدور على
   النطاق حتى الإيقاف اليدوي.
4. أثناء الاستماع العادي تُشتق «الآية الحالية» من موضع التشغيل والتوقيتات
   لتمييزها وتمرير الشاشة إليها.

مثال مطابق للمواصفات: البقرة ١–٥، كل آية ×٣ ←
١،١،١، ٢،٢،٢، ٣،٣،٣، ٤،٤،٤، ٥،٥،٥ (مغطّى باختبار آلي).

## البنية

```
lib/
  core/        الثيم + محرك التكرار النقي
  data/        النماذج، مستودع القرآن (JSON مضمّن)، قاعدة sqflite،
               الإعدادات (shared_preferences)، خدمة التنزيل
  features/
    audio/     معالج audio_service + وحدة تحكم بمشغّل واحد
    home/      الرئيسية (متابعة آخر جلسة، حلقة هدف اليوم، اختصارات)
    surah_index/  فهرس السور مع بحث وتصفية بالجزء
    mushaf/    المصحف: تمييز + تمرير تلقائي + حجم خط + قائمة الآية
    range/     اختيار النطاق وإعدادات التكرار
    player/    شريط المشغّل الدائم + شاشة المشغّل الكاملة
    memorize/ review/ stats/ favorites/ settings/
assets/data/   quran.json + timings.json (يولّدها tools/prepare_data.py)
tools/         prepare_data.py — تنزيل + تحقق صارم (يفشل بصوت عالٍ عند أي اختلاف)
docs/          SOURCES_AND_LICENSES.md — المصادر والتراخيص وتحفظ mp3quran
```

## بناء النشر على Windows (خطوات المستخدم)

1. أنشئ مفتاح الرفع مرة واحدة:
   `keytool -genkey -v -keystore %USERPROFILE%\upload-keystore-wird.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload`
2. أنشئ `android/key.properties` (لا يُرفع إلى Git أبدًا):
   ```
   storePassword=...
   keyPassword=...
   keyAlias=upload
   storeFile=C:/Users/<you>/upload-keystore-wird.jks
   ```
   المشروع يقرأ هذا الملف تلقائيًا ويوقّع به بناء Release، وبدونه يسقط
   توقيع Debug للبناء المحلي فقط.
3. البناء: `flutter build appbundle --release` ←
   `build/app/outputs/bundle/release/app-release.aab` لرفعه إلى Google Play،
   و`flutter build apk --release` للاختبار المباشر.
